音频工具 ffmpeg
还没检测到 ffmpeg，它是抽音轨和烧字幕的必需品。
从 gyan.dev 下载 ffmpeg-release-essentials.zip，解压后把 ffmpeg.exe 和 ffprobe.exe 复制到 bin\，然后刷新页面。

填一个 API Key 就能开始，推荐 DeepSeek（便宜且快）。
只存在本机 ~/.vidtrans/config.json，不会上传。
