# 放你自己的图（可选）

这个页面默认的赌场风格（猩红 × 黑金、扑克牌、轮盘）全部由 CSS 绘制，**不含任何第三方图片**。

如果你想把自己喜欢的角色图放上来：

1. 把图片命名为 **`yumeko.png`**
2. 放到这个 `assets/` 目录下（即 `vidtrans/web/assets/yumeko.png`）
3. 刷新页面即可 —— 顶部会出现一张主视觉卡片

图片要求：

- 格式：PNG（也可以是 JPG，改一下 `index.html` 里 `<img src="assets/yumeko.png">` 的后缀）
- 尺寸：正方形最好，页面按 `168×168` 圆角裁切显示；建议不低于 `400×400`
- 体积：建议 300KB 以内，太大加载会慢

没有图片时这块会自动隐藏，不影响任何功能。

**请只使用你有权使用的图片。**

（GitHub 上可能收到 DMCA 下架通知）。

想放的话，推荐：

- 自己画的 fan art
- 委托画师并取得授权的图
- 官方发布的「可自由使用」素材（如有）
- 或者只保留本项目自带的 CSS 赌场风格，也很契合

如果你 fork 了这个项目只是想自己本地用，那就随意了 —— 只要不提交到公开仓库就行。
