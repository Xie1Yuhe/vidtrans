# 示例

## `glossary.txt`

一份术语表样例，用日本动画/游戏直播里常见的词条演示格式：

```
廻珠 → 回珠
ゾーン → ZONE
伏黒恵 → 伏黑惠
```

**为什么需要它**：机器翻译很容易同一个词前后译法不一致（今天叫「领域」，明天叫「区域」）。
把对照表写清楚，翻译时会强制使用，整片译名就统一了。

**怎么用**

```bash
# 命令行
python app.py run 视频.mp4 --glossary examples/glossary.txt

# 网页：把内容粘到「② 翻译设置 → 术语表」
```

**写多少合适**

- 优先写「容易翻错的」：作品专有名词、角色名、技能名、单位
- 同一个词有多种官方译法时，选你观众的圈子最认的那个
- 几十条就够明显改善；几百条也不会拖慢多少

**关于格式**

- 分隔符用 `→` 或 `=`，两边空格可有可无
- `#` 开头的行会原样进提示词（模型能忽略），嫌吵就删掉
